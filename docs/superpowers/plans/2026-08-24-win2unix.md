# win2unix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Einmaliger Massen-Datentransfer von einem Windows-Server auf Mac/Linux — auf Windows wird nichts installiert, auf der Unix-Seite holt ein paralleles Skript einen Ordner mit beweisbarer Vollständigkeit.

**Architecture:** Drei Teile. (1) Ein portables cwRsync-Bundle plus `START-RSYNC-SERVER.cmd`, das per Doppelklick alle Laufwerke read-only als rsync-Module bereitstellt. (2) `pull.sh` auf der Unix-Seite: zerlegt den Quellordner in Arbeitspakete, überträgt sie parallel, korrigiert per Sweep-Pass und beweist per Verify-Pass die Vollständigkeit. (3) `tools/fetch-cwrsync.sh`, das das Windows-Bundle reproduzierbar neu baut.

**Tech Stack:** Bash (POSIX-nah, **bash 3.2**), `awk`, `xargs`, `split`, rsync-Daemon-Protokoll; Windows-Batch plus PowerShell für Laufwerks-Erkennung.

**Spec:** `docs/superpowers/specs/2026-08-24-win2unix-design.md` — Executor liest beide. Alle Abschnittsverweise (2.2, 5.3, …) beziehen sich auf die Spec.

## Global Constraints

- **bash 3.2 Kompatibilität ist Pflicht.** macOS liefert bash 3.2.57. Verboten: assoziative Arrays (`declare -A`), `mapfile`/`readarray`, `${var,,}`/`${var^^}`, `&>>`. Erlaubt: Prozess-Substitution, `export -f`.
- **`pull.sh` ist EINE Datei ohne `source`-Abhängigkeiten.** Es wird per `bash -c "$(curl …)"` ausgeführt; ein `source lib/x.sh` gäbe es dort nicht.
- **Nur openrsync-taugliche Optionen** (Spec 2.2). Erlaubt: `-r -l -t -d -W -n -i -8`, `--list-only`, `--files-from`, `--partial`, `--inplace`, `--numeric-ids`, `--exclude-from`, `--port`, `--stats`, `--timeout`. **Verboten:** `--info=progress2`, `--iconv`, `--out-format`, `--append-verify`, `-a`, `-z`, `-L`, `-c` (außer hinter `--checksum`-Flag).
- **Kein Intervall-Quantor (`{n}`) in awk-Regexen** — BSD-awk auf macOS unterstützt sie nicht zuverlässig. Zeichenklassen ausschreiben.
- **Variablen-Konvention:** PascalCase mit Unterstrich-Präfix (`_SrcUrl`, `_MaxRetry`), auch für lokale. Funktionen `w2u_*` in Kleinschreibung.
- **Zero-Touch:** keine Rückfragen, kein interaktiver Input. Alle Defaults als Variablen am Skript-Kopf.
- **Keine Listen über stdin.** Immer `--files-from=<datei>` und `xargs -a <datei>` (Spec 5.5/6).
- **Git:** Arbeit läuft auf `feat/implementation`, nicht auf `main`. Commit-Identität ist im Repo bereits gesetzt (`7onnie` / noreply-Adresse) — nicht überschreiben.
- Repo: `7onnie/win2unix`, Raw-Basis `https://raw.githubusercontent.com/7onnie/win2unix/main/`.

```bash
#!/usr/bin/env bash
# Minimales Assert-Harness. Keine Abhaengigkeiten - laeuft auf nacktem macOS mit bash 3.2.

_TestsRun=0
_TestsFailed=0

t_assert_eq() {
    local _Expected="$1" _Actual="$2" _Label="$3"
    _TestsRun=$((_TestsRun + 1))
    if [ "$_Expected" = "$_Actual" ]; then
        printf '  ok   %s\n' "$_Label"
    else
        _TestsFailed=$((_TestsFailed + 1))
        printf '  FAIL %s\n' "$_Label"
        printf '       erwartet: [%s]\n' "$_Expected"
        printf '       bekommen: [%s]\n' "$_Actual"
    fi
}

t_assert_contains() {
    local _Haystack="$1" _Needle="$2" _Label="$3"
    _TestsRun=$((_TestsRun + 1))
    case "$_Haystack" in
        *"$_Needle"*)
            printf '  ok   %s\n' "$_Label"
            ;;
        *)
            _TestsFailed=$((_TestsFailed + 1))
            printf '  FAIL %s\n' "$_Label"
            printf '       suchte:   [%s]\n' "$_Needle"
            printf '       in:       [%s]\n' "$_Haystack"
            ;;
    esac
}

t_assert_rc() {
    local _Expected="$1" _Actual="$2" _Label="$3"
    t_assert_eq "$_Expected" "$_Actual" "$_Label"
}

t_skip() {
    printf '  SKIP %s\n' "$1"
}

t_summary() {
    printf '\n%s: %d Tests, %d Fehler\n' "${0##*/}" "$_TestsRun" "$_TestsFailed"
    [ "$_TestsFailed" -eq 0 ] || exit 1
    exit 0
}
```

```bash
_LogDir=""             # leer = unter dem Zielverzeichnis anlegen

_DoVerify=1
_VerifyOnly=0
_DryRun=0
_DoChecksum=0

_SrcUrl=""
_DstDir=""
_DstRoot=""
_TmpDir=""
_ResultFile=""
_StartTs=0

w2u_warn() { printf '[%s] WARNUNG: %s\n' "$(date '+%H:%M:%S')" "$*" >&2; }

Aufruf: pull.sh [Optionen] rsync://<WIN-IP>/<modul>/<pfad> <zielverzeichnis>
```

```bash
# Liest ein rsync-Listing von stdin, schreibt "TYP<TAB>NAME".
# Format ist immer: perms size YYYY/MM/DD HH:MM:SS name
# --out-format wird von openrsync im Listing-Modus ignoriert (Spec 2.2), deshalb
# wird geparst statt formatiert. Der Name ist ALLES nach dem Zeitstempel, sonst
# gehen Leerzeichen verloren. Keine Intervall-Quantoren: BSD-awk kann sie nicht.
w2u_parse_listing() {
    awk '
    {
        sub(/\r$/, "")
        if (match($0, / [0-9][0-9][0-9][0-9]\/[0-9][0-9]\/[0-9][0-9] [0-9][0-9]:[0-9][0-9]:[0-9][0-9] /) == 0) next
        _Name = substr($0, RSTART + RLENGTH)
        if (_Name == "." || _Name == "") next
        if (substr($0, 1, 1) == "d") {
            printf "d\t%s\n", _Name
        } else {
            printf "f\t%s\n", _Name
        }
    }'
}
```

```bash
#!/usr/bin/env bash
# Startet einen echten rsync-Daemon fuer Tests. Braucht ein rsync mit --daemon;
# Apple-openrsync kann das NICHT, deshalb wird sauber geskippt statt zu scheitern.

D_Port=8873
D_Url=""
D_Dir=""
D_Bin=""

d_available() {
    for _C in /opt/homebrew/bin/rsync /usr/local/bin/rsync; do
        if [ -x "$_C" ] && "$_C" --version 2>/dev/null | head -1 | grep -q '^rsync  *version 3'; then
            D_Bin="$_C"
            return 0
        fi
    done
    return 1
}

d_start() {
    D_Dir="$(mktemp -d)"
    local _Serve="$1"
    cat > "$D_Dir/rsyncd.conf" <<EOF
use chroot = false
strict modes = false
max connections = 32
lock file = $D_Dir/rsyncd.lock
pid file = $D_Dir/rsyncd.pid
log file = $D_Dir/rsyncd.log
port = $D_Port
address = 127.0.0.1

[test]
    path = $_Serve
    read only = true
    list = yes
EOF
    "$D_Bin" --daemon --config="$D_Dir/rsyncd.conf"
    sleep 1
    D_Url="rsync://127.0.0.1:$D_Port/test"
}

d_stop() {
    [ -f "$D_Dir/rsyncd.pid" ] && kill "$(cat "$D_Dir/rsyncd.pid")" 2>/dev/null
    rm -rf "$D_Dir"
}
```

```bash
# Sucht ein brauchbares rsync. Auf den Ziel-Macs ist das Apple-openrsync
# (Protokoll 29) - das reicht als CLIENT vollstaendig aus (Spec 2.2).
w2u_find_rsync() {
    if [ -n "$_RsyncBin" ]; then
        [ -x "$_RsyncBin" ] || w2u_die "kein ausfuehrbares rsync unter $_RsyncBin"
        return 0
    fi
    local _C
    for _C in /opt/homebrew/bin/rsync /usr/local/bin/rsync; do
        if [ -x "$_C" ]; then
            _RsyncBin="$_C"
            return 0
        fi
    done
    _RsyncBin="$(command -v rsync 2>/dev/null || true)"
    [ -n "$_RsyncBin" ] || w2u_die "kein rsync gefunden"
    return 0
}

# Listet GENAU EINE Ebene unterhalb von <basis>/<rel>.
w2u_remote_list() {
    local _Base="$1" _Rel="$2" _Url
    _Base="${_Base%/}"
    if [ -n "$_Rel" ]; then
        _Url="$_Base/$_Rel/"
    else
        _Url="$_Base/"
    fi
    "$_RsyncBin" --list-only -d "$_Url" 2>/dev/null | w2u_parse_listing
}
```

```bash
# Zerlegt den Quellbaum in Arbeitspakete (Spec 5.3).
#
# Invariante: arbeit + queue ueberdecken zu jedem Zeitpunkt exakt den Baum.
# Wird ein Ordner expandiert, ersetzt ihn die VOLLSTAENDIGE Liste seiner Kinder -
# Dateien UND Ordner. Ein LEERER Ordner hat keine Kinder und muss deshalb selbst
# Arbeitspaket bleiben, sonst verschwindet er (im Test nachgewiesen).
w2u_decompose() {
    local _Base="$1" _Threshold="$2" _OutFile="$3"
    local _Cur="$_TmpDir/lvl.cur" _Next="$_TmpDir/lvl.next"
    : > "$_OutFile"
    printf '\n' > "$_Cur"          # eine leere Zeile = die Wurzel selbst
    local _CurCnt=1

    while : ; do
        local _WorkCnt
        _WorkCnt="$(grep -c . "$_OutFile" 2>/dev/null || true)"
        [ -n "$_WorkCnt" ] || _WorkCnt=0
        if [ $((_WorkCnt + _CurCnt)) -ge "$_Threshold" ]; then
            break
        fi

        : > "$_Next"
        local _AnyDir=0 _Rel _Type _Name _Path _EntryCnt
        while IFS= read -r _Rel; do
            _EntryCnt=0
            while IFS="$(printf '\t')" read -r _Type _Name; do
                [ -n "$_Name" ] || continue
                _EntryCnt=$((_EntryCnt + 1))
                if [ -n "$_Rel" ]; then
                    _Path="$_Rel/$_Name"
                else
                    _Path="$_Name"
                fi
                if [ "$_Type" = "d" ]; then
                    printf '%s\n' "$_Path" >> "$_Next"
                    _AnyDir=1
                else
                    printf '%s\n' "$_Path" >> "$_OutFile"
                fi
            done < <(w2u_remote_list "$_Base" "$_Rel")

            # Leerer Ordner: haette keine Kinder, muss selbst Arbeitspaket bleiben.
            if [ "$_EntryCnt" -eq 0 ] && [ -n "$_Rel" ]; then
                printf '%s\n' "$_Rel" >> "$_OutFile"
            fi
        done < "$_Cur"

        if [ "$_AnyDir" -eq 0 ]; then
            _CurCnt=0
            : > "$_Cur"
            break
        fi

        local _NextCnt
        _NextCnt="$(grep -c . "$_Next" || true)"
        mv "$_Next" "$_Cur"
        _CurCnt="$_NextCnt"
        if [ "$_NextCnt" -gt "$_MaxItems" ]; then
            w2u_warn "Ebene mit $_NextCnt Eintraegen ueberschreitet _MaxItems=$_MaxItems - keine weitere Expansion"
            break
        fi
    done

    # Restliche, nicht expandierte Ordner sind Arbeitspakete.
    grep -v '^$' "$_Cur" >> "$_OutFile" 2>/dev/null || true
    # Duplikate koennen nicht auftreten, aber leere Zeilen schon.
    grep -v '^$' "$_OutFile" > "$_OutFile.clean" || true
    mv "$_OutFile.clean" "$_OutFile"
}
```

```bash
# Uebertraegt einen Chunk (Spec 5.5).
#  -W  : Erstkopie, jede Datei ist neu - Delta-Algorithmus kostet nur CPU
#  -l  : Symlinks als Symlinks. NIEMALS -L, das folgt NTFS-Junctions in Schleifen
#  kein -a: -a zieht -pog mit, und Cygwin-Rechte sind synthetisch
#  kein -z: im LAN ist die CPU das Limit, nicht die Leitung
w2u_run_chunk() {
    local _ChunkFile="$1"
    local _Name _Try=1 _Rc=0
    _Name="$(basename "$_ChunkFile")"
    local _ExcludeOpt=""
    [ -n "$_ExcludeFrom" ] && _ExcludeOpt="--exclude-from=$_ExcludeFrom"

    while [ "$_Try" -le "$_MaxRetry" ]; do
        set +e
        if [ -n "$_ExcludeOpt" ]; then
            "$_RsyncBin" -rlt -W --partial --numeric-ids --stats \
                "$_ExcludeOpt" \
                --files-from="$_ChunkFile" \
                "$_SrcUrl/" "$_DstRoot/" > "$_LogDir/$_Name.log" 2>&1
        else
            "$_RsyncBin" -rlt -W --partial --numeric-ids --stats \
                --files-from="$_ChunkFile" \
                "$_SrcUrl/" "$_DstRoot/" > "$_LogDir/$_Name.log" 2>&1
        fi
        _Rc=$?
        set -e
        [ "$_Rc" -eq 0 ] && break
        [ "$_Try" -lt "$_MaxRetry" ] && sleep $((_RetryPause * _Try))
        _Try=$((_Try + 1))
    done
    [ "$_Try" -gt "$_MaxRetry" ] && _Try="$_MaxRetry"

    printf '%s\t%s\t%s\n' "$_Name" "$_Rc" "$_Try" >> "$_ResultFile"
    return 0
}
```

```bash
# Arbeitet eine Chunkliste mit <jobs> parallelen Prozessen ab.
# xargs liest aus einer DATEI (-a), niemals aus stdin: beim Bootstrap ueber
# bash -c "$(curl ...)" waere stdin sonst der Skript-Stream (Spec 6).
w2u_run_list() {
    local _ListFile="$1" _Jobs="$2"
    [ -s "$_ListFile" ] || return 0
    export _RsyncBin _SrcUrl _DstRoot _LogDir _ResultFile _MaxRetry _RetryPause _ExcludeFrom
    export -f w2u_run_chunk
    xargs -a "$_ListFile" -P "$_Jobs" -I {} bash -c 'w2u_run_chunk "$1"' _ {}
}

# Misst den Durchsatz bei steigender Parallelitaet (Spec 5.4).
# Die Probe-Arbeit ist echte Arbeit - es wird nichts verworfen.
w2u_autotune() {
    local _ListFile="$1"
    local _Rest="$_TmpDir/chunks.rest"
    cp "$_ListFile" "$_Rest"

    local _BestP=2 _BestRate=0 _P _Take _Round _Before _After _T0 _T1 _Dur _Kb _Rate
    for _P in 2 4 8; do
        [ "$_P" -gt "$_PMax" ] && break
        _Take=$((2 * _P))
        _Round="$_TmpDir/probe.$_P"
        head -n "$_Take" "$_Rest" > "$_Round"
        [ -s "$_Round" ] || break
        tail -n +$((_Take + 1)) "$_Rest" > "$_Rest.next" || true
        mv "$_Rest.next" "$_Rest"

        _Before="$(du -sk "$_DstRoot" 2>/dev/null | awk '{print $1}')"
        _T0="$(date +%s)"
        w2u_run_list "$_Round" "$_P"
        _T1="$(date +%s)"
        _After="$(du -sk "$_DstRoot" 2>/dev/null | awk '{print $1}')"

        _Dur=$((_T1 - _T0))
        [ "$_Dur" -lt 1 ] && _Dur=1
        _Kb=$((_After - _Before))
        [ "$_Kb" -lt 0 ] && _Kb=0
        _Rate=$((_Kb / _Dur))
        w2u_log "Messung P=$_P: ${_Rate} KB/s ueber ${_Dur}s"

        if [ "$_Rate" -gt $(( _BestRate + _BestRate / 7 )) ]; then
            _BestRate="$_Rate"
            _BestP="$_P"
        else
            # weniger als ~15 Prozent Zuwachs oder Rueckgang: hier ist Schluss
            break
        fi
    done
    printf '%s\n' "$_BestP"
}

w2u_run_all() {
    local _ListFile="$1" _Jobs
    if [ "$_JobCnt" -gt 0 ]; then
        _Jobs="$_JobCnt"
        w2u_log "feste Parallelitaet: $_Jobs (Auto-Messung uebersprungen)"
        w2u_run_list "$_ListFile" "$_Jobs"
    else
        _Jobs="$(w2u_autotune "$_ListFile")"
        w2u_log "gewaehlte Parallelitaet: $_Jobs"
        w2u_run_list "$_TmpDir/chunks.rest" "$_Jobs"
    fi
    _JobCnt="$_Jobs"
}
```

```bash
# Einzelner vollstaendiger Lauf ueber den Baum (Spec 5.6). Die Daten liegen
# bereits, das ist ein reiner Metadaten-Durchlauf: er korrigiert
# Verzeichnis-mtimes und faengt alles ab, was die Zerlegung ausgelassen haette.
w2u_sweep() {
    "$_RsyncBin" -rlt -W --partial --numeric-ids "$_SrcUrl/" "$_DstRoot/"
}

# Struktur-Verify (Spec 5.7). Erwartung: leere Ausgabe.
# Gefiltert wird AUSSCHLIESSLICH die mtime der Wurzel selbst - sie ist
# systematisch und harmlos. Wer pauschal alle .d-Zeilen wegwirft, wirft auch
# echte Befunde weg. Die Punktzahl im Itemize-String ist versionsabhaengig
# (openrsync 9 Zeichen, GNU rsync 11), deshalb der offene Quantor.
w2u_verify() {
    local _Out
    _Out="$("$_RsyncBin" -rlt -W -n -i "$_SrcUrl/" "$_DstRoot/" 2>&1 \
            | grep -Ev '^\.d\.\.t[.]* \./$' || true)"
    if [ -n "$_Out" ]; then
        printf '%s\n' "$_Out"
        return 1
    fi
    return 0
}

w2u_count_remote() {
    "$_RsyncBin" -r --list-only "$_SrcUrl/" 2>/dev/null | grep -c '^-' || true
}

w2u_count_local() {
    find "$_DstRoot" -type f | wc -l | tr -d ' '
}

# Abschlussbericht. Das PASS/FAIL-Kriterium ist explizit, weil daran haengt,
# ob die Quelle verschrottet werden darf.
w2u_report() {
    local _Fail=0 _Total _Bad _Retried _Dur _Remote _Local
    _Total="$(grep -c . "$_ResultFile" 2>/dev/null || echo 0)"
    _Bad="$(cut -f2 "$_ResultFile" 2>/dev/null | grep -vc '^0$' || true)"
    _Retried="$(awk -F'\t' '$3 > 1' "$_ResultFile" 2>/dev/null | grep -c . || true)"
    _Dur=$(( $(date +%s) - _StartTs ))

    printf '\n'
    printf '========================================================\n'
    printf ' win2unix %s - Abschlussbericht\n' "$W2U_VERSION"
    printf '========================================================\n'
    printf ' Quelle          : %s\n' "$_SrcUrl"
    printf ' Ziel            : %s\n' "$_DstRoot"
    printf ' Dauer           : %d s\n' "$_Dur"
    printf ' Parallelitaet   : %s\n' "$_JobCnt"
    printf ' Chunks          : %s gesamt, %s mit Wiederholung, %s fehlgeschlagen\n' \
           "$_Total" "$_Retried" "$_Bad"

    if [ "$_Bad" -gt 0 ]; then
        printf '\n FEHLGESCHLAGENE CHUNKS (Exit 23/24 = Dateien fehlen still!):\n'
        awk -F'\t' '$2 != 0 { printf "   %s  Exit %s\n", $1, $2 }' "$_ResultFile"
        _Fail=1
    fi

    if [ "$_DoVerify" -eq 1 ]; then
        _Remote="$(w2u_count_remote)"
        _Local="$(w2u_count_local)"
        printf ' Dateizahl       : remote %s / lokal %s\n' "$_Remote" "$_Local"
        if [ -n "$_ExcludeFrom" ]; then
            printf '   (Hinweis: Ausschluesse aktiv, Zahlen nur orientierend)\n'
        elif [ "$_Remote" != "$_Local" ]; then
            printf '   ABWEICHUNG in der Dateizahl!\n'
            _Fail=1
        fi
    fi

    printf '\n'
    if [ "$_Fail" -eq 0 ]; then
        printf ' ERGEBNIS: PASS - Transfer vollstaendig.\n'
    else
        printf ' ERGEBNIS: FAIL - NICHT verschrotten, Logs pruefen: %s\n' "$_LogDir"
    fi
    printf '========================================================\n\n'
    return "$_Fail"
}
```

```bash
w2u_parse_args() {
    local _Pos=0
    while [ "$#" -gt 0 ]; do
        case "$1" in
            --jobs)         _JobCnt="$2"; shift 2 ;;
            --exclude-from) _ExcludeFrom="$2"; shift 2 ;;
            --log-dir)      _LogDir="$2"; shift 2 ;;
            --rsync)        _RsyncBin="$2"; shift 2 ;;
            --verify-only)  _VerifyOnly=1; shift ;;
            --no-verify)    _DoVerify=0; shift ;;
            --checksum)     _DoChecksum=1; shift ;;
            --dry-run)      _DryRun=1; shift ;;
            --version)      printf 'win2unix pull.sh %s\n' "$W2U_VERSION"; exit 0 ;;
            -h|--help)      w2u_usage; exit 0 ;;
            -*)             w2u_die "unbekannte Option: $1" ;;
            *)
                if [ "$_Pos" -eq 0 ]; then
                    _SrcUrl="$1"
                elif [ "$_Pos" -eq 1 ]; then
                    _DstDir="$1"
                else
                    w2u_die "zu viele Argumente: $1"
                fi
                _Pos=$((_Pos + 1))
                shift
                ;;
        esac
    done

    [ -n "$_SrcUrl" ] || { w2u_usage; exit 2; }
    [ -n "$_DstDir" ] || { w2u_usage; exit 2; }
    case "$_JobCnt" in
        ''|*[!0-9]*) w2u_die "--jobs braucht eine Zahl, bekam: $_JobCnt" ;;
    esac
    case "$_SrcUrl" in
        rsync://*) : ;;
        *) w2u_die "Quelle muss mit rsync:// beginnen, bekam: $_SrcUrl" ;;
    esac

    # Zielpfad-Semantik wie bei rsync: Slash am Ende der Quelle entscheidet.
    _DstDir="${_DstDir%/}"
    case "$_SrcUrl" in
        */)
            _DstRoot="$_DstDir"
            _SrcUrl="${_SrcUrl%/}"
            ;;
        *)
            _DstRoot="$_DstDir/$(basename "$_SrcUrl")"
            ;;
    esac
}

w2u_preflight() {
    w2u_find_rsync
    w2u_log "rsync: $_RsyncBin ($("$_RsyncBin" --version 2>&1 | head -1))"
    case "$("$_RsyncBin" --version 2>&1 | head -1)" in
        *openrsync*) w2u_log "openrsync erkannt - kein --info=progress2, kein --iconv (beides unkritisch)" ;;
    esac

    [ -d "$_DstDir" ] || w2u_die "Zielverzeichnis existiert nicht: $_DstDir"
    [ -w "$_DstDir" ] || w2u_die "Zielverzeichnis nicht beschreibbar: $_DstDir"
    [ -z "$_ExcludeFrom" ] || [ -r "$_ExcludeFrom" ] || w2u_die "Ausschlussdatei nicht lesbar: $_ExcludeFrom"

    "$_RsyncBin" --list-only -d "$_SrcUrl/" >/dev/null 2>&1 \
        || w2u_die "Quelle nicht erreichbar: $_SrcUrl (laeuft START-RSYNC-SERVER.cmd? Port 873 offen?)"

    mkdir -p "$_DstRoot"
    if [ -z "$_LogDir" ]; then
        _LogDir="$_DstRoot/.win2unix-logs"
    fi
    mkdir -p "$_LogDir"
}

w2u_cleanup() {
    local _Rc=$?
    [ -n "$_TmpDir" ] && [ -d "$_TmpDir" ] && rm -rf "$_TmpDir"
    return "$_Rc"
}

main() {
    if [ "$#" -eq 0 ]; then
        w2u_usage
        exit 2
    fi
    _StartTs="$(date +%s)"
    w2u_parse_args "$@"

    _TmpDir="$(mktemp -d)"
    trap 'w2u_cleanup' EXIT
    trap 'w2u_warn "abgebrochen - erneuter Aufruf setzt fort"; exit 130' INT TERM

    w2u_preflight
    _ResultFile="$_TmpDir/results"
    : > "$_ResultFile"

    if [ "$_VerifyOnly" -eq 1 ]; then
        w2u_log "nur Verifikation"
        w2u_verify || true
        w2u_report
        exit $?
    fi

    w2u_log "zerlege $_SrcUrl"
    w2u_decompose "$_SrcUrl" $((_ThresholdFactor * _PMax)) "$_TmpDir/work"

    if [ "$_DryRun" -eq 1 ]; then
        w2u_log "dry-run: $(grep -c . "$_TmpDir/work") Arbeitspakete, nichts uebertragen"
        head -20 "$_TmpDir/work"
        exit 0
    fi

    mkdir -p "$_TmpDir/chunks"
    w2u_chunk "$_TmpDir/work" "$_TmpDir/chunks" "$_PMax" "$_TmpDir/chunks.list"
    w2u_run_all "$_TmpDir/chunks.list"

    w2u_log "Sweep-Pass"
    w2u_sweep >> "$_LogDir/sweep.log" 2>&1 || w2u_warn "Sweep meldete Fehler, siehe $_LogDir/sweep.log"

    if [ "$_DoVerify" -eq 1 ]; then
        w2u_log "Verifikation"
        w2u_verify > "$_LogDir/verify.log" 2>&1 || true
        if [ -s "$_LogDir/verify.log" ]; then
            w2u_warn "Verify meldet Abweichungen:"
            head -50 "$_LogDir/verify.log" >&2
            w2u_report || true
            exit 1
        fi
    fi

    w2u_report
    exit $?
}
```

`README.md`:

````markdown
# win2unix

Einmaliger Massen-Datentransfer von einem alten Windows-Rechner auf Mac oder Linux.
Auf Windows wird **nichts installiert** — ein Ordner wird kopiert und eine Datei angeklickt.

Gedacht für den Fall: mehrere hundert GB bis mehrere TB, sehr viele kleine Dateien,
danach wird die Windows-Kiste verschrottet.

## Auf dem Windows-Rechner

1. Den Ordner `windows/` auf die Windows-Kiste kopieren (USB-Stick oder Netzwerkfreigabe).
2. `START-RSYNC-SERVER.cmd` **als Administrator** ausführen (Doppelklick genügt — das Skript
   fordert die Rechte selbst an).
3. Das Fenster offen lassen. Es zeigt die IP-Adressen an, unter denen der Server erreichbar ist.

Administrator-Rechte sind nicht optional: ohne sie kann der Server fremde Benutzerprofile nicht
lesen und lässt still Dateien aus.

## Auf dem Mac oder Linux-Rechner

Erst schauen, was es gibt:

```bash
rsync rsync://<WINDOWS-IP>/          # welche Laufwerke?
rsync rsync://<WINDOWS-IP>/e/        # was liegt auf E:?
```

Dann holen:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/7onnie/win2unix/main/pull.sh)" -- \
     rsync://<WINDOWS-IP>/e/Archiv /opt/data/files/
```

**Nicht `curl … | bash` verwenden.** Dabei ist die Standardeingabe der Skript-Stream selbst, und
die internen Dateilisten würden den restlichen Skriptcode lesen.

Bricht der Transfer ab — Netzwerk, Strom, versehentlich geschlossenes Fenster —, einfach denselben
Befehl erneut ausführen. Es wird nur geholt, was fehlt.

### Ohne Skript

Der Weg funktioniert auch mit blankem rsync, das Skript ist nur schneller:

```bash
rsync -rltP -W rsync://<WINDOWS-IP>/e/Archiv /opt/data/files/
```

Der Unterschied: `pull.sh` zerlegt den Ordner und überträgt parallel. Bei tiefen Bäumen voller
kleiner Dateien ist das typischerweise Faktor 4–6, weil ein einzelner rsync-Prozess auf Windows
in der Cygwin-Schicht CPU-gebunden ist. Dazu kommt die Verifikation.

### Optionen

| Option | Wirkung |
|---|---|
| `--jobs N` | feste Parallelität statt Auto-Messung |
| `--exclude-from DATEI` | Ausschlussmuster |
| `--verify-only` | nur prüfen, nichts übertragen |
| `--dry-run` | zeigt die Arbeitspakete, überträgt nichts |
| `--checksum` | Verifikation zusätzlich mit Prüfsummen (liest alles erneut, grob 1–2 h pro TB) |

## Wann ist es fertig?

Am Ende steht ein Bericht mit **PASS** oder **FAIL**. PASS heißt: der Vergleichslauf gegen die
Quelle ist leer und die Dateizahlen stimmen überein. Erst dann darf die Quelle verschrottet werden.

FAIL nennt die fehlgeschlagenen Chunks. Exit-Code 23 oder 24 bedeutet, dass Dateien nicht gelesen
werden konnten — meist gesperrt durch ein laufendes Programm. Programme schließen, Lauf wiederholen.

## Sicherheit

Der Transfer ist **unverschlüsselt und nicht authentifiziert**. Solange der Server läuft, kann
jeder im selben Netz die freigegebenen Laufwerke lesen. Das ist bewusst so: reines LAN, einmaliger
Vorgang, und Verschlüsselung würde die CPU der alten Quelle zum Flaschenhals machen.

Abgesichert ist es durch `read only`, eine Beschränkung auf das lokale Subnetz, und dadurch, dass
der Server nur läuft, solange das Fenster offen ist. Bei schutzbedürftigen Daten gehört der
Transfer in ein eigenes Netzsegment oder an ein Direktkabel.

## Lizenz

Die mitgelieferten Windows-Binärdateien stammen aus cwRsync free edition und stehen unter der
GPLv3 — siehe `windows/NOTICE.md`.
````
